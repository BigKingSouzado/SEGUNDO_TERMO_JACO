Artigos Rapidos

<h1> — Título

A tag <h1> é usada para criar o título principal de uma página. É o título mais importante do conteúdo.

<p> — Parágrafo

A tag <p> serve para adicionar textos em formato de parágrafo. É uma das tags mais utilizadas em HTML.

<a> — Link

A tag <a> permite criar links para outras páginas, sites ou partes do próprio documento.

<img> — Imagem

A tag <img> é utilizada para inserir imagens em uma página HTML. Ela normalmente utiliza o atributo src para indicar o endereço da imagem.

<button> — Botão

A tag <button> cria um botão interativo. Ela pode ser usada em formulários ou junto com JavaScript para executar ações.

<ul> e <li> — Lista

As tags <ul> e <li> são usadas para criar listas. A primeira define a lista e a segunda representa cada item.

<input> — Campo de entrada

A tag <input> cria campos para o usuário inserir informações, como nome, e-mail, senha ou números.

<form> — Formulário

A tag <form> é utilizada para criar formulários que permitem coletar informações dos usuários.
